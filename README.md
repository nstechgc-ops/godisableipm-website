# godisableipm.com

Website for God Is Able International Prayer Ministries. Built and managed by NS Tech Global Consulting.

- **Edit:** https://app.pagescms.org → sign in with GitHub → open this repo → edit → Save. Live in about a minute.
- **Hosting:** Cloudflare Pages (build `npm run build`, output `_site`).
- **Forms:** sent by FormSubmit to the email in Site settings (first submission needs a one-time confirmation click in that inbox).
